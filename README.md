## Selected Work

**[Full Quaternion-Based Attitude Control for a Quadrotor](https://github.com/Sainath-Reddy7/Drones_S5_CD_12_Full_Quaternion_Based_Attitude_Control_for_a_Quadrotor)**
Complete reproduction of Fresk &amp; Nikolakopoulos (ECC 2013) with a full 6-DOF SITL pipeline — deployed and verified on gym-pybullet-drones, MuJoCo, Gazebo, and ArduPilot. [Live demo](https://quadrotor-quaternion-sim.vercel.app).
`Control Systems` `Quaternion Math` `SITL`

**[Explainable RL for Energy-Efficient Cloud Resource Scheduling](https://github.com/Sainath-Reddy7/Explainable-Reinforcement-Learning-for-Energy-Efficient-Cloud-Resource-Scheduling)**
Double DQN cloud–edge scheduler with a from-scratch KernelSHAP explainability layer, trained on real Google Borg traces and audited with six trust metrics. Benchmarked against seven baselines — pure NumPy, no deep-learning frameworks.
`Reinforcement Learning` `Explainability` `Cloud Systems`

**[Secure Smart Grids — ICS Cybersecurity Framework](https://github.com/Sainath-Reddy7/Secure-Smart-Grids)**
Hybrid security framework for smart-grid ICS: Random-Forest anomaly detection, Isolation-Forest zero-day detection, Edge AI deployment, and ECC-AES-GCM encryption over IEC 60870-104 and IEC 61850 MMS.
`Cybersecurity` `ICS/SCADA` `Applied Cryptography`

**[V-Cards — AI Business-Card Extraction Pipeline](https://github.com/Sainath-Reddy7/V-cards-)**
AI-powered OCR pipeline converting business-card images into structured, validated JSON — supporting local GPU processing and cloud-based reasoning.
`Computer Vision` `OCR` `Data Pipelines`

*Further work:* [Quantum-MicroKPNN-MT](https://github.com/Sainath-Reddy7/Quantum-MicroKPNN-MT) · [EEG Signal Acquisition](https://github.com/Sainath-Reddy7/EEG_Signal_Acquisition) · [C++ DSA Templates](https://github.com/Sainath-Reddy7/cpp-dsa-templates-)
